# 나의 루틴 PWA v2

무제한 습관 관리. 이전 v1 데이터는 같은 브라우저/설치 앱에서 자동 유지됩니다.

## 새 기능
- 전체 루틴: ⠿ 터치/마우스 드래그, ▲▼ 버튼으로 순서 변경
- 달력: 월별 체크 달성 현황, 날짜 선택
- 연속 달성일: 예정된 반복 횟수를 기준으로 계산. 오늘 미완료는 아직 연속 기록을 끊지 않음
- 반복: 매일 / 요일 선택 / N일마다 / 매월 지정일 또는 말일
- 앱 내부 위젯형 요약 카드, 홈 화면 아이콘 배지(지원 기기에서만)
- 알림 희망 시간 저장(실제 자동 알림 아님)
- v1/v2 JSON 백업 및 복원

## GitHub Pages 배포/업데이트
1. 먼저 기존 앱 **설정 → JSON 백업** 을 실행해 파일을 안전한 곳에 보관합니다.
2. ZIP을 풀고 `index.html`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`를 기존 GitHub 저장소의 최상위에 업로드합니다. 기존 파일과 같은 이름으로 **덮어쓰기(Commit changes)** 합니다.
3. GitHub 저장소 Settings → Pages에서 `main` / `/(root)` 상태를 확인합니다.
4. iPhone의 기존 홈 화면 앱을 닫았다가 다시 실행하고 인터넷 연결 상태에서 새 버전을 확인합니다. 캐시 갱신은 추가 재실행이 필요할 수 있습니다.
5. 원래 앱 아이콘은 삭제하지 마세요. 삭제 시 로컬 데이터가 소실될 수 있습니다.

## 중요 제한
- PWA는 iOS의 네이티브 홈 화면/잠금 화면 위젯을 제공하지 않습니다. 앱 안의 요약 카드만 표시합니다.
- 백엔드가 없는 정적 GitHub Pages 웹앱만으로 종료 중 예약 시각의 iOS 푸시를 전송할 수 없습니다. iOS 16.4+ 홈 화면 웹앱의 웹 푸시를 구현하려면 구독 정보 저장 및 발송 서버가 필요합니다.
- 서버 동기화 없음. iPhone과 Windows의 저장 데이터는 별개입니다.
- 무료 Public GitHub 저장소에 개인 습관 백업(JSON)을 업로드하지 마세요.
