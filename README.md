# 나의 루틴 v4.0 (서버 없는 개인용 PWA)

## 설치/업데이트
기존 GitHub Pages 저장소 루트에 index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png를 업로드합니다. 업데이트 전에 앱 내 JSON 백업을 저장하세요. 기존 홈 화면 앱을 삭제하지 마세요.

## v4 알림의 정확한 한계
- 루틴별 시각은 10분 간격이며 각 루틴의 알림 체크박스를 켜야 합니다.
- 앱이 화면에 열려 있고 실행 중이면 15초마다 현재 시간과 반복 일정을 확인해 앱 내부 알림 배너를 표시합니다.
- 앱을 닫거나 백그라운드로 보내면 iPhone에서 실행이 일시 정지될 수 있습니다. 잠금화면/종료 상태에서 정시 알림을 발송할 수 없습니다.
- 다시 앱을 열면 오늘 놓친 미완료 루틴을 알립니다. 한번 확인한 루틴 알림은 같은 날짜에 중복 표시하지 않습니다.
- 서버, 푸시 구독 및 단축어 연동이 제거됐습니다. 이 앱은 iOS 시스템 알림을 예약하지 않습니다.
- iPhone에서 앱이 닫힌 상태로 정확한 시간에 알림을 받으려면 네이티브 iOS 앱의 로컬 알림 또는 외부 푸시 서버가 필요합니다.

## 데이터
기존 personal-routine-v1 로컬 저장 키를 그대로 사용합니다. 백업·복원 기능이 있습니다.
