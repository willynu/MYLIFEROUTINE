# 나의 루틴 v4.1

기존 v4 데이터 키(`personal-routine-v1`)를 유지합니다. ZIP의 5개 PWA 파일을 GitHub Pages 저장소에 업로드하세요. `SHORTCUT_SETUP.md`를 꼭 읽고 iPhone에서 단축어를 수동으로 한 번 구성해야 합니다.

**중요:** 동기화 버튼은 iPhone 클립보드에 향후 30일 예정 알림을 복사한 뒤 Shortcuts URL Scheme을 통해 이름이 `나의루틴 알림동기화`인 단축어를 호출합니다. 이는 iOS 미리 알림 생성 완료를 검증하지 않습니다. 반드시 미리 알림 앱에서 생성 여부를 확인하고 앱으로 돌아와 `단축어 실행 완료 확인` 버튼을 누르세요. iPhone 기기에 따라 단축어 동작 이름과 권한 확인이 다를 수 있습니다.

날짜별 알림은 30일 앞까지 생성되므로 매주 갱신하는 방식이며 영구 반복은 아닙니다. 인터넷 서버가 필요하지 않습니다.
